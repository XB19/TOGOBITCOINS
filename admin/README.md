# Togo Bitcoin — Admin

Interface d'administration locale du site. Lit et écrit directement les fichiers
`src/data/*.json` et les images de `src/assets/events/` et `src/assets/partners/`
du projet principal, via l'API du dossier `../server`.

Voir le README à la racine du projet pour les instructions de lancement
(`npm run admin` depuis la racine).
